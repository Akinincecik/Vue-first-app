# Vue First App

This project is a simple blog page developed using the Vue.js framework. The goal is to experiment with frontend development processes using Vue and explore what can be done with this technology.

## 🎯 Project Purpose

Vue.js is a popular JavaScript framework used to build modern, reactive user interfaces. This project was developed as an entry point into the Vue ecosystem and to learn its core building blocks.

It is an experimental work aimed at broadening my perspective and seeing what can be done with Vue.

## 🛠️ Features

- Simple blog interface
- Use of Vue component structure
- Listing and viewing content
- Beginner-level project layout

## 🚀 Technologies Used

- Vue.js (v2 or v3 - depending on the project setup)
- HTML & CSS
- JavaScript (ES6+)
